# Discord RPC (prototype Windows)
Opt-in: config/nova-discord.properties est créé au premier lancement. Fermer le jeu avant de modifier si souhaité. Renseigner applicationId avec l'identifiant d'une application Discord créée dans le portail développeur, nommée Nova Client. Aucun token ni secret nécessaire. enabled=true active la présence. showServerName=false protège le nom du serveur; aucune adresse IP n'est lue. showTimer contrôle le chronomètre. Les changements sont relus toutes les 15 secondes. Discord Desktop doit être ouvert. Aucun bouton d'invitation ni secret de connexion. Le protocole IPC et les mappings Minecraft restent à tester; pas encore de menu graphique de configuration.
