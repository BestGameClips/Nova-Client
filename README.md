# Nova Portable — experimental source rebuild
Extract the entire ZIP, run NovaLauncher.exe on Windows x64 with WebView2 available, select an existing folder. Node is bundled. Java 25 and Minecraft assets/libraries are downloaded and checked. Vineflower decompiles only TitleScreen and LoadingOverlay; original Nova source modifies the generated Java, javac recompiles selected classes, jar updates a local copy of the game. Generated JAR remains local; do not distribute it. The GitHub workflow builds the portable EXE and tests the source patch helpers, not the copyrighted game JAR.
Known limits: exact game API signatures and decompiler output must be verified; recompilation can fail. Microsoft authentication, direct launching, Discord RPC, full UI settings and FPS optimizations not implemented. Local nickname is UI-only. No Fabric/Mixin/agent. First install requires network. Use a dedicated empty installation folder.
