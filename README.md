# Nova Native 0.2 experimental
Java 25 agent, without Fabric, modifies title-screen background and loading overlay at runtime using the JDK ClassFile API. No Minecraft game files distributed. Build with npm run build; local game download/decompilation with npm run decompile. The agent is not a standalone game; launcher must pass -javaagent:<absolute path> to Minecraft's Java process. Hooks are experimental and require in-game verification. Discord RPC and a full custom GUI are not yet ported.
